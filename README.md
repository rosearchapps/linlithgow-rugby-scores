# Linlithgow Rugby Scores

A match-day score keeper for Linlithgow rugby, built for parents on the touchline.

## What it does

- Pick the opponent from a list of Scottish clubs, and their colours show on their side of the scoreboard
- Home or away, worked out from your location, and grounds are remembered after the first visit
- Age group sets the match time and half lengths (Scottish Rugby maximum times)
- Match clock with stoppages, half time, and time-up "play on" counting
- Tries, conversions, penalty goals, drop goals and penalty tries, with the scorer's name
- Paste WhatsApp commentary and it slots in at the right minutes
- Photos stamped with the match minute and score
- Full-time summary you can share as an image or text
- Previous matches, with a two-step delete

## Folders

| Folder | What it is |
| --- | --- |
| `index.html` | The whole app in one file. Open it in a browser, or publish it with GitHub Pages. |
| `iphone-app/` | The same app wrapped as a real iPhone app (photos save to a "Linlithgow Rugby Scores" album). See `iphone-app/README.md`. |

## Use it on a phone with GitHub Pages

1. In this repository, go to **Settings > Pages**.
2. Under **Branch**, choose `main` and `/ (root)`, then **Save**.
3. After a minute you'll get a link like `https://<your-username>.github.io/linlithgow-rugby-scores/`.
4. Open it in Safari, tap **Share > Add to Home Screen**.

Matches made this way are saved on that phone only.

## Updating

Replace `index.html` with the new version (and `iphone-app/www/index.html` for the iPhone app), then commit.
